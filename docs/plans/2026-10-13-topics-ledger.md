# Topics and Shared Ledger Implementation Plan

**Goal:** 在已有小队中加入实时话题聊天、语音留痕、聊天 PDF 导出，以及各自记账和共享统计。

**Architecture:** 复用设备会话、小队权限、JSON 持久化与 SSE。话题消息分页加载，SSE 只推送摘要；语音保存在非公开数据目录并经过小队鉴权读取。账单金额使用整数分，按北京时间的支出日期统计。

**Tech Stack:** Node.js 核心模块、原生 JavaScript/CSS、MediaRecorder、浏览器打印为 PDF；不增加生产依赖。

## 确认范围

- 用户已选择各自记账＋共享统计，不加入代付、均摊或转账。
- 默认人民币；本人登记开支，所有小队成员可查看；仅本人可更正或删除自己的账单。
- 话题和消息对当前小队所有成员可见。消息发送后保留，不提供撤回。
- 原始语音可试听、发送、播放、下载，最长 2 分钟/5 MB。不做自动转写。
- PDF 使用浏览器“保存为 PDF”，包含完整话题、时间、发送人、文字及语音回听链接；音频另行下载，链接仍需原小队身份和可访问的服务器。
- 保留现有用户数据；兼容缺少新字段的旧数据文件。

## 实施与验证

1. 新增 `public/community-domain.js` 的金额校验/筛选统计；在 `tests/community.test.mjs` 验证小数精度、合法日期、成员归属和月份筛选。
2. 新增 `community-server.mjs`，修改 `server.mjs` 接入话题、分页消息、受保护音频、导出页面、账单接口。测试房间隔离、幂等发送、文件限制、并发和重启持久化。
3. 新增 `public/community.js` 和相关 CSS，修改 `public/app.js`、`public/sw.js`。完成五栏导航、话题列表/聊天、录音试听、账本概览/筛选/本人更正。
4. 新增 `scripts/community-browser-test.mjs`，在独立临时数据中测试两个会话同步、输入不被新消息打断、录音与上传、PDF 中文排版、账单金额/权限和移动端布局。重跑现有回归检查。
5. 更新 README/验收记录；备份当前数据后重启应用提供最新页面，不清除或覆盖用户记录。

## 已知运行条件

手机浏览器直接录音需要 HTTPS；localhost 开发可录音，局域网 HTTP 提供音频文件上传。公网部署仍是独立未执行事项。当前目录不是 Git 仓库，因此不创建 worktree 或提交。
