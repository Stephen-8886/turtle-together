# 移动端流体动效

本次仅更新本地 PWA，停止 GitHub 上传和云端部署操作。

- 新建话题、记账、邀请等按钮到弹窗：520ms 高阻尼尺寸、位置、圆角与背景过渡；内容延后淡入，关闭回到原入口。
- 任务/话题卡片到详情：捕获点击前矩形，背景容器连续展开，正文轻微缩放淡入；账单卡片到详情弹窗复用流体容器。
- 按钮：按下 0.96 缩放与内阴影，释放 1.018 轻微超调后回到 1；支持键盘及取消按压。
- 导航：按照六个导航位置决定左右方向，旧页面退出、新内容滑入，底部导航稳定。
- 快速连点会取消旧转场并清理不可交互的视觉副本；系统减少动态效果直接切换。

验证：独立临时数据库与无头 Edge 的 6 组交互检查通过，包含聊天提交、Escape、快速导航、减少动态效果和 320/390/1280 宽度。无页面脚本错误。
