# Server Clock, Accounts and Native Clients Implementation Plan

**Goal:** 服务器独立判定任务计时和权限；账号跨设备恢复，团队数据隔离；交付内置前端资源的 Windows / Android 客户端。

**Architecture:** 保留单实例 Node 服务和原子文件存储，新增账号/会话模块、服务器时间投影。网页通过 HttpOnly Cookie 使用 API；原生壳内置相同 public 资源，通过仅监听回环地址的代理连接明确配置的 HTTPS 后端。客户端只展示服务器推送的状态与剩余时间。

**Tech Stack:** Node crypto scrypt, HTTP/SSE, Windows Forms + WebView2, Android Java WebView + NanoHTTPD.

## Decisions

- 服务器保存时间戳并每秒推送投影，不为每项任务维护容易随重启丢失的内存计数器。重启/关闭客户端后重新计算，不自动把专注到时等同于任务完成，仍需本人确认。
- 账号密码使用带随机盐的 scrypt，随机会话凭据仅持久化哈希，注销撤销服务端会话。成员 ID 保留，原浏览器身份可以绑定账号，避免丢失原任务、聊天、账单及奖励。
- 小队成员身份关联账号；只允许通过邀请加入或在已加入的小队间切换。计划在小队内可见，个人写入权限继续按 memberId 校验。
- 独立原生壳比继续只做 PWA 安装包更符合内置界面需求；完整重写为原生 UI 会重复现有界面/动画逻辑，暂不采用。壳依赖系统 WebView / Chromium，计时不依赖壳进程存活。
- 单实例 + 持久数据卷适合目前两人使用；不引入多节点调度/Redis。部署前先备份整个 data，生产必须 HTTPS、持久卷和单副本。

## Tasks and verification

1. 新增 server-clock.mjs 和 clock 测试：服务器生成今日/选定日/跨夜专注状态、操作许可、结算。SSE 单一时钟循环，关闭服务时释放。验证本机传入时间无效、超时拒绝、重启恢复。
2. 新增 auth-server.mjs 和 auth 测试：注册/登录/退出/绑定旧身份，团队列表/切换，多设备会话、会话失效、密码哈希、速率限制和跨队隔离。旧匿名建队仅显式测试选项开启，默认关闭。
3. 修改 public/app.js：账号入口/小队选择/绑定，任务和结算使用后端投影；秒级事件只更新计时 DOM，保留聊天/表单草稿。去除客户端时间规则判定。
4. 新增 clients 下桌面壳、Android 工程、界面资源复制及构建脚本。代理限制回环来源、后端固定 HTTPS，原生壳禁用 Node 渲染权限和外部导航。
5. 使用临时数据运行 npm test 和浏览器双账号验收；构建能用的安装包，记录 SDK/签名限制，不能以源工程冒充安装包。
6. 更新 Docker、部署文件、README 和版本缓存。用户已选择先本地版本与安装包，暂不部署；仅准备代码及本地体验包。

## Completed verification

- 后端测试 31 项、账号/计时浏览器检查 9 项、原任务浏览器回归 14 项、讨论/账单浏览器回归 15 项通过。
- 实际 Windows WebView2 客户端 4 项流程检查通过，包含服务器计时和聊天 PDF 子窗口。
- Android 本地调试 APK 已编译，v2/v3 签名校验通过；未连接真机，因此未宣称安装、麦克风或后台恢复实测。
- ZIP 白名单与内置 Android 资源一致性检查通过，打包 Node 可独立启动后端并注册账号；不包含用户数据、测试账号或签名密钥。
- 本地体验包默认绑定回环地址。自动审批曾拒绝自动将真实数据服务开放至局域网；没有执行该操作，已有 4173 服务未被改动。局域网连接仅提供用户手动配置说明。
