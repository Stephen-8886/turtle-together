# 龟龟同频 2.0 · 本地客户端

此版本包含独立后端、Windows exe 客户端、Android 本地测试 APK。没有上传到公网。

## 先启动后端

已有开发目录：双击工程中的 `start.cmd`，数据继续使用原来的 `data`，不需要迁移。

本地体验包：解压完整 ZIP，双击 `backend/start-backend.cmd`，默认仅允许本机访问。包内带 Node 运行时，无须另装 Node；数据保存在 `%LOCALAPPDATA%/TurtleTogetherBackend/data`。此目录与开发目录不同，第一次运行是空的小森林。不要把两个数据目录相互覆盖；需要沿用原记录时，关闭后端后备份并复制整个旧 `data`（包括 `media`）到目标目录。

同一时间只启动一个 4173 后端。关闭后端时界面仍可打开，但不能登录或同步；服务器重新启动后按保存的开始/截止时间恢复状态，期间经过的时间仍计入。

## Windows

解压完整 ZIP 后双击 `windows/TurtleTogether.exe`，保留同目录的 DLL、public、runtime 和脚本。不要只复制 exe。

默认连接 `http://127.0.0.1:4173`。窗口顶部「服务器设置」可以改为 HTTPS 后端地址；改变地址后重启客户端，并使用独立登录缓存，避免将原服务器凭据发给另一个地址。

界面资源包含在本地包中，采用微软 WebView2 显示，不需要打开外部浏览器。此电脑已有 WebView2 Runtime；其他 Windows 电脑如提示缺少运行时，请从微软官网下载 Evergreen WebView2 Runtime：<https://developer.microsoft.com/microsoft-edge/webview2/>。Windows 客户端为 x64，使用 .NET Framework 4.8。未购买代码签名证书，文件为本地未签名体验版。

聊天「导出 PDF」会打开原生子窗口，可用窗口顶部「保存为 PDF / 打印」或页面里的打印按钮导出。录音首次使用需同意麦克风权限。

## Android

将 `android/TurtleTogether-2.0.0-local.apk` 传到手机安装。Android 8.0 及以上，需要支持现代网页功能的 Android System WebView。本地测试包使用调试签名，不是应用商店正式发行版。

第一次打开填写后端地址。手机通过局域网连接前，先关闭原来的后端，在解压后的 `backend` 文件夹打开命令提示符，依次运行以下两行，主动开启局域网访问：

```cmd
set HOST=0.0.0.0
start-backend.cmd
```

与电脑同 WiFi 时，手机填写电脑的局域网 IP，如 `http://192.168.1.20:4173`；手机上的 localhost 指向手机本身，不能填电脑的 `127.0.0.1`。电脑需要允许此服务的 4173 入站连接。只在可信本地网络测试 HTTP；正式联网客户端使用 HTTPS。

顶部菜单可修改服务器、重新同步、打印 / 保存 PDF。录音需 Android 麦克风权限；拒绝后仍可发文字或上传已有语音。

本地 APK 已编译并通过签名与包信息校验；本机没有连接 Android 真机或模拟设备，因此没有进行手机安装、录音和后台恢复实测。安装包内置 UI，关闭手机 App 不影响后端计时；没有实现 App 关闭后的系统推送。

## 账号与共享

新用户先注册账号（3–32 位英文、数字、点、下划线或短横线），密码 10–128 字符，然后创建或通过邀请码加入小队。伙伴用自己的账号加入同一小队。

同一个账号在手机/电脑登录，会恢复同一成员 ID，不会新建一个同名成员。一个账号可以加入多个小队，通过「我的小窝 → 账号与小队」切换。跨队不能读取任务、聊天、音频或账单；同队可见内容沿用原来的共享规则，个人写入权限仍受服务端限制。

原来已登录的浏览器身份：在「我的小窝」点「绑定账号」，原成员 ID、任务、聊天、账单、奖励均保留。尚未绑定时不要清除浏览器数据；已丢失的旧设备凭据不能仅凭昵称找回。

密码使用随机盐 scrypt 哈希；会话为 HttpOnly Cookie，服务器只存凭据哈希。退出会撤销该会话，修改密码会撤销所有其他设备会话。目前没有邮件找回密码或账号合并。

## 计时规则

任务是否适用于当天、是否逾期、能否开始/完成以及结算结果都由后端生成。服务器每秒经 SSE 推送剩余时间，前端只显示它，不在客户端倒数到零后自行准许完成。断线时冻结最后同步的数值，禁用完成按钮，提示等待服务器。

开始时间持久化，刷新、换设备、退出客户端或重启后端均不会重新开始。到时只允许本人确认完成，不自动把离开的时间当成任务已完成。修改客户端页面里的时间或伪造请求里的剩余时间无法绕过服务端校验；后端以运行它的电脑或服务器的系统时间为准。

## 重建

- `npm test`：后端、账号、权限、计时和客户端代理测试。
- `node scripts/accounts-browser-test.mjs`：真实浏览器双账号及服务器计时验证。
- `node scripts/community-browser-test.mjs`：聊天、语音、PDF、账本回归。
- `node scripts/windows-browser-test.mjs`：隐藏原生 Windows 客户端验证，使用临时数据。
- `scripts/build-windows.ps1`：从当前 source 构建 exe，`-WebViewSdk` 指定微软 SDK 解压目录。
- `scripts/build-android.ps1`：使用官方 Android 35 平台、build-tools 35、JDK 17+ 和 NanoHTTPD 2.3.1 构建本地 APK；脚本使用命令行资源/Java/DEX/签名工具，不依赖 Gradle 下载。`-AndroidTools` 指定解压后的平台和工具目录，`-NanoHttpd` 指定 JAR。Android 工程也可用 Android Studio 打开并按其 Gradle 配置构建。
- `scripts/package-local.ps1`：将已构建的两个客户端和后端整理成 ZIP，同时生成 SHA256 文件；按文件白名单打包，不包含现有用户数据。

编译缓存、签名密钥、测试账号和真实个人数据均不放进体验包。正式发布需要保管自己的发布签名，并另外完成手机实测和 HTTPS 后端部署。
