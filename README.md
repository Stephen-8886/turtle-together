# 龟龟同频

绿色小乌龟主题的移动端共享任务清单。四象限计划、专注陪伴、伙伴督促、话题聊天和共享账本，已连接真实的多人同步后端。

## 启动

安装 Node.js 20 或更新版本。在本目录打开终端：

```powershell
npm start
```

也可以双击 `start.cmd`。无需安装 npm 依赖。打开 <http://localhost:4173>，填写昵称并创建小队。

手机和电脑连接同一 Wi-Fi，手机浏览器访问 `http://电脑的局域网IP:4173`。例如电脑的 IPv4 地址是 `192.168.1.8`，则访问 `http://192.168.1.8:4173`。可以在 Windows 的网络属性或 `ipconfig` 中查看 IPv4 地址；若 Windows 弹出防火墙提示，仅在你信任的私人网络允许 Node.js。

服务默认监听 `0.0.0.0:4173`。在同频小队页面复制邀请链接，由伙伴在各自手机打开。每个浏览器保留独立身份；同一个浏览器的标签页共用身份。两人测试请使用不同浏览器或无痕窗口。

## 已实现

- 四象限：重要且紧急、重要但不紧急、不重要但紧急、不重要且不紧急。
- 任务开始日期、可选开始时间、持续时长、截止日期/时间和备注；支持仅一次、每天、每周多选、重复结束日期及跨夜。
- 创建个人计划，或创建全体伙伴分别完成的共同任务。小队内互相查看计划和进度。
- 幸运转盘：完成一周内（周一至周日）的全部承诺，当天领小叶子时自动获得 1 张抽奖券；逾期与例外不算，整周无承诺不发。房主（最早加入的伙伴）在「我的小窝」设置 2–12 个奖品，持券伙伴转动转盘抽奖——服务端随机开奖、券留痕防重复、中奖记录全员同步。
- 添加任务的原文提示、勾选承诺和提交前确认。提交后任务内容与时间不可修改；例外记录保留原始承诺。
- 服务端强制检查开始时间、专注时长和截止时间，刷新、切换页面不会重置计时。
- 三种随机小乌龟待机动画；默认三张本地风景插画轮播；可导入最多 8 张风景照片，仅保存在本设备。
- 每位成员完成当天全部任务后自动出现奖励动画、结算专注时间并收集小叶子。
- 邀请加入、实时计划同步、督促动画、60 秒督促冷却、免打扰、未读督促保留与已读确认。
- PWA 清单、桌面图标、离线应用外壳和上次计划快照。离线时不提交、完成或伪造共享操作。
- 移动端布局、键盘焦点、对话框、中文标签及系统“减少动态效果”偏好。
- 共同话题、双方实时文字聊天、语音录制/试听/发送/播放/下载；发送人和北京时间留痕，刷新及服务重启后仍可回看。
- 聊天记录导出页面，使用浏览器“保存为 PDF”导出完整历史（不受聊天分页限制）。
- 人民币共享账本：本人登记开支、伙伴共同查看；月份/成员/分类筛选、逐人和分类金额统计、本人更正/删除。

## 一起聊聊与共享账本

底部「一起聊聊」→「新建一个话题」，填写名称和可选说明。所有小队成员可进入该话题；聊天消息发送后保留，不提供撤回。文字草稿保存在当前设备；已发送消息在服务器保存，消息列表每次加载 100 条，可点击“查看更早的消息”。新消息不会清空正在输入的内容。

点击「录语音」并授权麦克风，点击「停止并试听」，确认后再点「发送」。离开话题会停止录音并保留当前页面中的试听草稿；未发送的语音不会上传，刷新会丢失，浏览器支持时会提示。每条语音最长 2 分钟、5 MB，可附文字备注；也可上传 WebM、Ogg、M4A、MP3、WAV 文件。手机直接录音需要 HTTPS，电脑 localhost 可以录音；局域网 HTTP 下可上传已有语音。不会自动转写语音。

在话题右上角点击「导出 PDF」，新页点击「保存为 PDF」，在浏览器打印窗口中选择保存为 PDF；手机也可通过浏览器分享/打印菜单保存。PDF 包含完整文字、发送人、时间、语音时长及回听链接，不嵌入音频。语音链接仍要求当前浏览器具有原小队身份、服务器在线且地址可访问；长期备份请另行点击消息下的「下载原始语音」。导出文件使用导出时的服务器地址，从 localhost 导出的回听链接不能直接供异地伙伴使用。

底部「共享账本」→「记一笔我的开支」，填写名称、人民币金额、支出日期、分类及可选备注。按支出日期统计月份，金额用整数“分”计算。顶部显示当月小队总支出，下方人员/分类图和明细随筛选变化。可补记过去的支出，不接受未来日期、0、负数或超过两位小数的金额。点击明细可看备注，本人可更正或确认删除；别人不能修改。多人页面同时更正同一笔账单时，旧版本提交会被拒绝，避免覆盖新内容。不包含均摊、借贷、转账或银行自动导入。

话题、聊天和账单仅在同一小队内共享；邀请持有者加入后也能查看这些内容。需要先登录账号；旧设备身份应先绑定账号。离线可看上次同步的账本与话题摘要，完整聊天加载、语音和导出需要联网；已在当前页面加载的聊天可以继续查看。

## 规则与边界

时间统一使用北京时间（Asia/Shanghai），时间规则与任务操作许可由后端计算并每秒推送；前端只显示服务器剩余时间，断线时禁用完成。开始时间持久化，重启后按服务器时间恢复。0 分钟任务按截止时间完成；大于 0 的任务需要先开始专注，完整走完时长后才能确认完成。计时衡量经过的时间，不监控使用者的注意力。

重复任务按每个发生日期、每位成员分别记录；跨夜任务可以继续完成前一日尚未截止的专注。单次跨日任务在日期范围内持续显示，完成后不会在下一天重置。

例外或逾期不算成功完成，也不能获得当天的全清奖励。新增当天任务后，需要把新增任务也完成才能再次结算；相同任务集合的奖励不会重复发放。

当前支持账号密码登录，同一账号跨设备恢复同一成员。旧设备身份可在「我的小窝」绑定账号，保留全部记录。退出会撤销当前会话；修改密码会撤销其他设备会话。邀请码用于加入团队，不能代替账号登录；暂不支持邮件找回密码。

网页保持连接时，督促实时送达；关闭应用期间的督促在下次打开时出现。可选浏览器通知也需要页面保持连接。当前没有关闭应用后的系统推送服务。

## 互联网分享与 PWA 安装

局域网 HTTP 地址可用于手机浏览和多人同步。正式的互联网访问与完整 PWA 安装需要自己的 HTTPS 域名/服务器；本项目未自动发布到公网。

可以直接部署 Node 服务，或使用提供的 Dockerfile：

```sh
docker build -t turtle-together .
docker run -d --name turtle-together -p 4173:4173 -v turtle-data:/app/data turtle-together
```

在受信任的 HTTPS 反向代理后运行时，设置 `TRUST_PROXY=1`，让代理传递正确的 `Host` 和 `X-Forwarded-Proto: https`；将反向代理转发至 4173 端口，并关闭 `/api/events` 的响应缓冲。部署在域名根路径 `/`，使用单个 Node 实例与持久化数据卷。

通过 HTTPS 打开后，安卓浏览器可选择“安装应用”，iPhone Safari 可在分享菜单选择“添加到主屏幕”。应用内“我的小窝”也提供安装入口。

## 数据与维护

任务、话题、消息元数据和账单保存在 `data/rooms.json`，使用临时文件加原子重命名持久化；原始语音保存在 `data/media/`，通过鉴权接口播放/下载，不放入公开目录。备份请复制整个 `data` 目录。旧数据缺少话题/账单/账号字段时会自动兼容，不清除任务或身份；新增 accounts、sessions 保存账号哈希和可撤销会话。数据目录不应公开托管或提交到 Git。服务端只返回当前房间数据；会话凭据采用 HttpOnly Cookie，文件中仅保留哈希。

当前小队上限为 500 个话题、10000 条消息、250 MB 语音和 10000 笔账单。达到上限时明确提示，不自动删除历史记录。聊天使用分页读取，SSE 只发送话题摘要，不推送完整历史或语音内容。

环境变量：`PORT`（默认 4173）、`HOST`（默认 0.0.0.0）、`DATA_DIR`（默认 ./data）、`TRUST_PROXY`（仅在受信任代理后设为 1）。

## 文件

- `server.mjs`：房间、成员、任务、督促、奖励与实时同步。
- `auth-server.mjs`：账号密码、可撤销会话、旧身份绑定和团队权限。
- `server-clock.mjs`：服务器时间、任务许可与结算投影。
- `clients/windows`、`clients/android`：内置前端的独立客户端。
- `docs/local-clients.md`：本地安装包使用、账号迁移与构建说明。
- `community-server.mjs`：话题、消息、受保护语音、聊天导出和账单接口。
- `public/community.js`、`public/community-domain.js`：话题/账本界面、录音和金额/筛选逻辑；`public/export.*` 为 PDF 导出排版和打印入口。
- `public/domain.js`：日期、重复规则、任务校验与结算。
- `public/app.js`、`public/styles.css`：移动界面与交互。
- `public/assets/`：从 Figma 下载的四份乌龟 SVG、本地风景插画和 PWA 图标。
- `design.mjs`：Figma 页面初始构建脚本；后续布局修正的当前状态以 Figma 文件为准。
- `tests/app.test.mjs`、`scripts/browser-test.mjs`：业务与浏览器验证。
- `docs/verification.md`：需求逐项验收记录及剩余事项。
