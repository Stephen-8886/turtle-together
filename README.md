## 为什么做这个程序

做「龟龟同频」的初衷很简单：我想和伴侣共同努力、共同进步。

我们各自有想完成的事，也有一起向往的生活。认真学习、规律运动、合理安排开支，或者留一点时间好好聊聊——这些事情看起来很小，却一点点组成了两个人的未来。

我想把“我们一起加油”变成生活里具体的行动：看见对方今天的计划，在需要的时候轻轻提醒；一起完成一个小目标，再认真庆祝；把讨论过的想法和共同生活的记录留下来，回头看看我们走了多远。

于是有了这只小乌龟。它陪着我们专注、守约，也提醒我们给成长一点耐心。

**慢一点没关系，愿意一起向前就好。**

## 我希望它带来的改变

- **让陪伴更具体**：知道彼此正在为什么努力，在对方需要时给予支持。
- **让承诺更认真**：添加任务前想清楚能投入多少时间，然后一步步完成。
- **让沟通有留痕**：把共同关心的话题、想法与决定好好保存。
- **让生活有方向**：一起看见时间花在哪里、钱花在哪里，慢慢找到适合两个人的节奏。
- **让进步被记住**：完成清单时有一点小小的仪式感，平常的一天也值得庆祝。

它从两个人的需求出发，也支持与朋友组成小队，一起学习、运动或完成共同目标。

## 可以一起做什么

### 把计划放进四个象限

按照重要性与紧急程度整理任务，把注意力留给真正想完成的事。

| | 紧急 | 不紧急 |
| --- | --- | --- |
| **重要** | 重要且紧急 | 重要但不紧急 |
| **不重要** | 不重要但紧急 | 不重要且不紧急 |

任务可以设置开始日期、可选开始时间、专注时长、截止时间与备注，支持单次、每天、每周指定日期，以及跨夜安排。你可以创建自己的计划，让伙伴看见进度；也可以创建共同任务，由每位伙伴分别完成。

添加任务时，程序会提醒：

> 添加的任务需要严格遵循任务的持续时间/截止时间来，不可反悔，添加任务前需要三思。

确认提交后，任务内容与时间会被锁定。遇到特殊情况可以留下例外记录，原来的承诺仍然保留。希望我们在许下承诺之前，多一点认真，也给彼此留出理解和沟通的空间。

### 有一只小乌龟陪你专注

打开任务，可以让小乌龟动画陪伴专注，也可以选择风景轮播或导入自己喜欢的照片。倒计时与任务状态由后端判定，刷新页面、换设备或重新打开客户端，都能恢复原来的进度。

完成当天全部任务后，会出现庆祝动画，并收集一片小叶子。还有幸运转盘、轻食与运动记录，让日常坚持多一点期待。

### 看见彼此，也轻轻提醒

双方使用各自的账号加入同一小队，可以实时查看彼此的计划与完成情况。点击督促按钮，伙伴会收到一个提醒动画；督促设有冷却时间，也可以开启免打扰。

希望每一次提醒，都来自我们事先约好的支持。忙碌时可以各自专注，需要时也知道对方就在身边。

### 把想说的话好好留下

为共同关心的事情新建话题，在话题里发送文字或语音。无论是下一次旅行、一个生活上的决定，还是最近的心情，都可以有一个专门的地方慢慢聊。

聊天记录保留发送人和时间，支持通过打印功能保存为 PDF。语音可以单独下载；PDF 保留语音信息与回听链接，音频本身不嵌入文件。

### 一起了解生活里的开支

各自记账，共同查看。共享账本支持按月份、成员与分类统计开支，也能为每笔支出补充备注。每个人管理自己的记录，伙伴可以了解整体情况。

把这些记录作为沟通的起点，逐渐形成适合两个人的消费习惯。

## 从哪里开始

需要 **Node.js 20 或更新版本**。进入项目目录后运行：

```sh
npm start
```

项目运行不需要额外安装 npm 依赖。打开 [http://localhost:4173](http://localhost:4173)，然后：

1. 注册并登录自己的账号，创建一个小队。
2. 把小队邀请码或邀请链接分享给伙伴。
3. 伙伴使用自己的账号加入同一小队。
4. 各自添加一个小目标，开始一起行动。

同一个账号在不同设备登录，会恢复同一成员的计划与记录。已有旧设备身份的用户，可以在「我的小窝」绑定账号，保留原来的内容。

### 手机与伙伴如何连接

所有成员需要连接到**同一个后端服务**，共享内容才能实时同步。

源码通过 `npm start` 启动时，默认监听 `0.0.0.0:4173`。在可信的同一局域网中，手机可以访问电脑的局域网地址，例如 `http://192.168.1.20:4173`；电脑需允许对应端口的连接。手机中的 `localhost` 指向手机自身。

不同 Wi-Fi 或使用移动网络时，需要把后端部署到双方都能访问的 HTTPS 地址。GitHub 用于托管源码，在线共享仍需单独运行后端。当前版本没有提供公共托管服务。

### 网页与本地客户端

| 使用方式 | 当前说明 |
| --- | --- |
| 移动网页 / PWA | 移动端优先；通过 HTTPS 访问时可使用支持的浏览器安装到桌面 |
| Windows 客户端 | x64，基于 WebView2 与 .NET Framework 4.8，内置界面资源 |
| Android 客户端 | Android 8.0+，内置界面资源；目前为调试签名的本地测试版，尚未真机测试 |

仓库包含客户端源码与构建脚本，安装、构建及服务器地址配置见 [本地客户端说明](docs/local-clients.md)。完整本地体验包的后端启动脚本默认仅允许本机访问，与源码启动的默认监听方式不同。安装包需要自行构建或另行提供，未包含在源码文件中。

## 关于时间、数据与隐私

- **时间由后端决定**：使用北京时间处理任务日期与重复安排，剩余时间、逾期、完成权限和结算由后端生成。开始时间会保存，重启后按后端系统时间恢复；到时仍需本人确认完成。
- **断线时保留边界**：可以查看部分已缓存内容，提交任务、确认完成、发送消息和共享同步需要后端在线。关闭客户端不会重置计时；计时记录经过的时间，不监测注意力。
- **账号与小队隔离**：同一小队成员可以查看共享计划、讨论和账本，不同小队的数据互相隔离。请只邀请愿意共同分享这些内容的人。
- **数据由后端保存**：任务、账单、账号与聊天元数据保存在 `data/rooms.json`，语音保存在 `data/media/`。备份时请保存整个 `data` 目录，上传仓库时不要提交真实个人数据。
- **当前仍有待完善的地方**：暂不支持邮件找回密码、应用关闭后的系统推送、账单均摊结算或银行自动导入。网页直接录音需要 HTTPS，电脑 localhost 可用于本地录音。

## 开发与验证

前端使用 HTML、CSS 与 JavaScript，后端使用 Node.js，通过 SSE 同步状态。Windows 与 Android 客户端复用同一套界面，并连接独立后端。

```sh
npm test
```

测试覆盖任务时间规则、账号与成员权限、团队隔离、奖励结算、实时同步、聊天及账单等核心逻辑。

| 位置 | 内容 |
| --- | --- |
| `public/` | 界面、动画、风景素材与 PWA 资源 |
| `server.mjs`、`server-clock.mjs` | 任务、服务器计时、奖励与实时同步 |
| `auth-server.mjs` | 账号、会话与团队身份 |
| `community-server.mjs` | 话题、语音、聊天导出与共享账本 |
| `clients/` | Windows 与 Android 客户端源码 |
| `tests/` | 核心业务测试 |

## 写在最后

我希望「龟龟同频」能成为两个人生活里一个温柔的小角落：有各自认真生活的样子，也有共同努力的痕迹。

今天完成一件小事，明天再向前一点。等回过头时，希望我们都能说：

**和你一起，我成为了更好的自己。**
